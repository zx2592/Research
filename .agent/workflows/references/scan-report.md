## Step 4: 保存与通知

### 保存报告

1. 先 `check_report_quality(markdown)`；`passed: false` 时按 `missing_sections` / `issues` 补齐后重跑。
2. 通过后把完整报告保存到 `Reports/YYYYMMDD/YYYYMMDD_Market_Scan.md`（IDE 模式用文件写入工具，VPS 模式调 `write_to_file()`）。
3. **落盘是必须动作**：不得只在对话里回复、更不得假报已保存。

### 推送通知（仅 VPS 模式）

VPS/Telegram 模式下，向用户推送精简摘要（≤200字）：

```
[YYYYMMDD] 全球市场扫描完成
────────────────────────
综合体温: [体温判断]
今日主线: [一句话]
焦点市场: [市场名] ([状态])

持仓预警: [有/无] — [如有，列出受影响标的]
核心机会: [最高价值的 1-2 条机会线索]
首要风险: [最需要关注的 1 条风险]

报告: Reports/YYYYMMDD/YYYYMMDD_Market_Scan.md
```

IDE 模式下无需单独推送，报告内容已在对话中呈现。
