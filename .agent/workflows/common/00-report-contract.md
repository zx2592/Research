# 公共报告契约

所有工作流的最终报告必须结论先行，并且必须能被读者直接用于研究或决策。报告不得只给叙述性观点，必须把关键结论、证据、数据快照、反方情景和行动计划放在固定位置。

## 必需结构

每份写入 `Reports/` 的 Markdown 报告必须包含以下章节：

1. `# 报告标题`
   - 标题必须含 `[YYYYMMDD]`，日期取 `Date Context` 注入的联网日期（凭训练记忆写日期算幻觉）
2. `## 结论先行`
   - **一行判决**：`评级[强多/多/中性/空/强空] · 动作[买/加/持/减/卖/观察/继续研究/不通过] · 置信度[高/中/低] · 一句理由(≤30字)`
   - 本次判断相对上次是否变化（无历史标「🆕首次」）
   - **价格证据行**（吃价格的工作流必写，见下）
3. `## 实时数据快照`
   - 必须调用 `get_realtime_quote(ticker)` 获取最新行情
   - 涉及交易、估值、盈亏比、止损价、目标价时，必须调用 `cross_validate_price(ticker)`
   - 写明价格、涨跌幅、来源、抓取时间、交叉验证是否通过
4. `## 证据台账`
   - 用表格列出关键判断、证据、来源、日期、证据等级、对结论的影响
   - 表格必须有**数据行**，只有表头不算；无源判断不进表，移入「风险与不确定性」并标「推断」
   - 必含至少一行**反方 (Bear)** 证据
5. `## Bull/Base/Bear`
   - 至少列出 Bull、Base、Bear 三种情景，概率合计 100%，Base 为当前最可能
   - 每种情景必须说明触发条件、关键假设、12M 目标和需要观察的指标
6. `## 行动计划`
   - 给出可执行动作、触发器、失效条件、下一次复盘点
   - 执行细节必须能照做：仓位 % / 价格区间 / 时间窗
   - 必须写明**看错信号**（出现什么就退出）
7. `## 风险与不确定性`
   - 明确哪些信息不足、哪些是假设、哪些数据可能延迟或失真
   - 必须含 `### 证据缺口` 小节：逐条写 `[缺什么] — [影响哪个判断] — [下一步去哪取]`；确无缺口写「关键判断均有 T1/T2 支撑」
8. `## 质量自检`
   - 保存前必须调用 `check_report_quality(markdown)`
   - 只有质检通过后才能调用 `write_to_file`
   - 末尾盖印章：`✅ 质量Gate 8/8` 或 `⚠️ N/8，未过项见风险与不确定性`

## 关键变化与数字底稿（决策/深度类必写）

涉及买卖、估值、组合、深度研究的工作流，在 `## 证据台账` 之后补两节：

- `## 关键变化` — 对照上次档案：基本面 / 价格 / 估值 / 仓位 / 逻辑 / 风险变了什么（⬆️改善 / ⬇️恶化 / ↔️无变）；无历史标「🆕首次」。
- `## 数字底稿` — 决策硬数字集中放，每个带时间 + 来源层级：

  | 指标 | 数值 | 时间 | 层级 | 备注 |
  | :-- | :-- | :-- | :-- | :-- |
  | 价格 / 估值(FwdPE·PEG·历史分位) / 增长 / 盈利 / 仓位 / 盈亏比 | | | | |

## 价格证据行

结论先行区必须有一行，按 `cross_validate_price` 的**实际返回**二选一如实写：

- `价格证据：HK$153.70 · T2×2 已交叉（cross_validate_price passed=true, spread 0.13%，2026-08-20T07:31Z）`
- `价格证据：HK$153.70 · T2 单源未交叉（get_realtime_quote，2026-08-20T07:31Z）`

规则：

- 「已交叉」是 `cross_validate_price(ticker)` **算出来的结论**，不是自己声明的。工具返回 `passed: false` 或 `error: fewer than two price sources` 时，只能写「单源未交叉」。
- **单源不是违规，是未过项**：如实申报后报告照常落盘，但**不得给目标价、止损与盈亏比**。不写这一行才是硬伤——不申报比申报单源更糟，读者连「该不该信」都无从判断。
- 「独立的第二个来源」指**不同源头**，不是同一份数据的两个门面。腾讯财经、东方财富、新浪、同花顺、雪球、交易所官网都在转发同一份交易所行情，互相比对**不构成交叉**；真正的第二源要跨族：公司公告 / 年报原文、券商终端、路透 / 彭博、另一市场的 ADR 报价等。
- **偏差恰好 0.00% 是同源的证据，不是最高可信度**：两个真正独立的来源（一家用最新成交、一家用官方收盘）几乎不可能分毫不差。`spread_pct` 为 0 时先确认不是同一份数据，确认不了按单源处理。
- **为什么放在结论区**：价格是目标价、止损、盈亏比、仓位金额的分母。埋进第三节表格的备注列时，读者读的是结论那一段——于是一个单源数字看起来和交叉过的一模一样。

## 写作纪律

- 事实、观点、推断必须分开写。
- 没有来源的数字不得写入结论区。
- 不得把社媒传言、单篇新闻、卖方观点写成确定事实。
- 不得省略反方观点。
- 不得只输出摘要，必须保存完整报告。
