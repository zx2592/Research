# 公共证据契约

## 证据等级

| 等级 | 类型 | 例子 | 使用规则 |
| --- | --- | --- | --- |
| Tier 1 | 一手原始信号 | 公司公告、SEC/交易所文件、财报电话会原文、管理层原话、监管文件、专利、招聘、Form 4、成交和行情数据 | 核心事实和关键数字优先使用；关键结论尽量 ≥3 处 T1 |
| Tier 2 | 权威事实整理 | 交易所摘要、财务数据库、公司 IR 页面、主流财经媒体事实报道、法院文书 | 可用于补全事实，核心数字必须能回溯到此层，关键数字需要交叉验证 |
| Tier 3 | 观点与解释 | 卖方研报、新闻分析、专家评论、社媒讨论、目标价 | 只能作为观点输入，**不能作为唯一证据**；社媒一律标「未证实」 |
| Tier 4 | 推断 | 模型自己的逻辑推导、情景假设、反推估值 | 必须标注为推断或假设 |

新闻分级顺序：一手公告 / 电话会 (T1) > 主流媒体事实报道 (T2) > 媒体解读 (T3) > 卖方观点 (T3) > 社媒传言 (T3，标「未证实」)。

## 联网取证必须走本项目自己的工具

`search_web` / `browser_fetch` / `browser_operate` / `drill_source` / `learn_source` / `get_realtime_quote` / `cross_validate_price` / `cross_validate_metric` / `get_financials` / `verify_market_cap` / `execute_python_script`。

宿主 Agent 自带的搜索后端或研究技能同样查得到答案，但那条路上的原文本项目一个字也留不下：证据台账无从回溯、`Reports/Raw_Data` 里没有记录、事后没人能把某个结论展开回当时那一页。**用别家工具取到的内容，在本项目等于没有证据。**

研究类工作流整轮**一次联网取证都没有**，报告不得落盘（代码校验：报告里必须留下
`fetched_at` / `verdict` / `consensus_price` 这类真实取数痕迹）。

## 时效协议：训练记忆里的财报一律视为过期

最常见的一类错误不是算错，是**拿训练数据里的旧财报当最新**——它读起来完全正常，
数字齐整、口径统一，只是晚了两个季度。取任何「最新」数据前按顺序做完四步：

1. **写下今天日期** — 用 `Date Context` 注入的联网日期，不是凭记忆。
2. **搜最新** — 明确带上年份与季度检索（如 `NVDA latest earnings 2026 Q2`）。
3. **验证时点** — 确认拿到的财报发布日在最近 3 个月内；超出则说明是否有更新一期尚未取到。
4. **核对原文日期** — 电话会纪要、公告 PDF 必须核对文首日期，不能只信检索结果摘要。

写进报告的每一个财务数字都要带**所属期**（`FY25` / `2026Q2`），不带期数的数字等于没有口径。

## 数据源优先级（按市场）

**先走结构化接口，再走网页正文。** 从新闻或研报正文里读营收、净利、现金流、ROIC，是数字出错的第一现场——口径不明、时点不明，常常还是别人算过一手的。

| 市场 | 主源 | 副源（交叉用） | 一手披露（对不上时以它为准） |
| --- | --- | --- | --- |
| A股 | `get_financials(ticker)`（东方财富结构化年报，已直连） | 巨潮资讯 cninfo.com.cn | 交易所公告 / 年报 PDF |
| 美股 | macrotrends.net/stocks/charts/{ticker} | stockanalysis.com/stocks/{ticker}/financials | SEC EDGAR 10-K / 10-Q 原文 |
| 港股 | aastocks 公司基本面 | macrotrends（ADR 代码，如 0700→TCEHY） | HKEX 披露易 hkexnews.hk 年报 |
| 台股 | FinMind api.finmindtrade.com | Goodinfo goodinfo.tw | 公开资讯观测站 MOPS |

副源不是"随便再找一个网站"：**同族来源互相比对不构成交叉**（见下）。接口覆盖不到的市场，用 `browser_fetch` / `drill_source` 回主源与副源取数，再用 `cross_validate_metric` 把两个数值算一遍。

## 来源族：什么才算"独立的第二个来源"

腾讯财经、东方财富、新浪、同花顺、雪球、Tushare 都在转发同一份交易所行情——它们同属一族，互相比对得到的 0.00% 偏差不是最高可信度，是**同一份数据比了两遍**。

| 族 | 成员 | 说明 |
| --- | --- | --- |
| `intl-vendor` | Yahoo / yfinance / fetch_market_prices | 国际行情供应商链路 |
| `cn-exchange-relay` | 腾讯、东财、新浪、同花顺、雪球、Tushare | 交易所行情转发 |
| `tw-vendor` | FinMind、Goodinfo | 台股 |
| `primary-disclosure` | 交易所公告、巨潮、HKEXnews、SEC、公司 IR | 一手披露，冲突时以它为准 |

`cross_validate_price` 已按族判定：跨族才算交叉，同族一律按单源处理，跨族数值完全相同也按疑似同源处理。

## 误差分级（交叉后怎么写）

| 误差 | 处理方式 |
| --- | --- |
| ≤ 1% | ✅ 一致，取共识值（中位数），标注两个来源 |
| 1% ~ 5% | ⚠️ 标「数据存在差异」，并列写出两个数值，说明可能原因 |
| > 5% | ❌ 标「重大差异」，必须回原始披露核实，**不得直接使用** |

常见差异原因（不一定是数据错）：GAAP vs Non-GAAP、汇率换算时点、财年定义（如苹果财年 10 月结束）、合并口径是否含少数股东权益、某平台尚未更新最新一期。

呈现格式：

```
收入：1,239亿元 ✅
  - 东方财富: 1,241亿元
  - 巨潮年报: 1,237亿元
  - 误差: 0.3%
```

## 股价复权口径（历史序列必读）

三种口径混用会让历史股价位置、长期涨幅、历史估值分位全部失真：

| 口径 | 含义 | 用途 |
| --- | --- | --- |
| 不复权 | 实际成交价，除权除息日跳空 | 只用于"当前时点"快照 |
| 前复权 | 以最新价为基准回调历史价 | 历史股价对比、N 年涨幅、历史 PE band 一律用它 |
| 后复权 | 以上市首日为基准前推 | 计算历史总回报 / 年化收益 |

1. 涉及历史价格的分析统一用**前复权**，同一份报告内**不得混用**复权与不复权来源。
2. 当前市值 / 当前 PE 用**当前实际股价 × 当前总股本**，与复权无关。
3. 跨越拆股 / 大比例送转的每股指标（历史 EPS、历史股价）必须复权还原后再同比。
4. 总回报 / 年化收益需计入分红（后复权已含），只看价格涨幅会低估。
5. 增发 / 回购后用 `verify_market_cap(price, shares, reported_cap)` 验算，偏差 >5% 先核对股本口径再用。

## 缺失与估算：留空是最坏的写法

表格里的空格没有含义——读者分不清是「查了没有」「忘了填」还是「不适用」。
给模型一条合法出路，是为了让它不必在「留白」和「编造」之间二选一：

| 情况 | 写法 | 说明 |
| --- | --- | --- |
| 查过，确实没有披露 | `-` | 不是所有公司都披露分部数据 |
| 本项不适用 | `N/A` | 如未盈利公司的 PE |
| 自己推算的数字 | 数值后加 `[E]` | 如 `毛利率 42%[E]`，并在备注写推算方式 |
| 有判断但取不到证据 | `[UNSOURCED]` | 判断保留，明确标记无源，落盘时会被计数 |

**`[UNSOURCED]` 不是免罪符**：它让「无源」变得可见、可统计、可在下一轮补上，
但一份到处是 `[UNSOURCED]` 的报告仍然不可用于决策。取证预算耗尽时用它如实收尾，
而不是把没有证据的判断写成事实。

## 溯源即时化：取到就写，不要留到最后补

每取到一个数字，**当场**在证据台账里补上对应行（判断 / 证据 / 来源 / 日期 / 等级 / 影响）。
不要写 `TODO: 补来源`、不要打算「最后统一整理」——留到最后时，上下文里最早那几次
取证的原始链接和抓取时间往往已经被挤掉了，于是要么漏掉，要么凭印象补一个近似的来源。
这是证据台账失真最主要的成因。

## 强制规则

- 价格、估值、财务预测、仓位和交易建议必须带**来源 + 时间**。**无时间戳 = 过期**，不作决策依据。
- 实时行情必须至少使用 `get_realtime_quote`；涉及行动价、盈亏比、止损或目标价时必须使用 `cross_validate_price`，并把结果写进结论先行区的「价格证据行」。
- 财务和估值数字必须用**两个独立族的来源**交叉验证：取到两个数后用 `cross_validate_metric(field, values, unit)` **算**一遍，按上表的误差分级如实写；无法交叉时在 `风险与不确定性` 中说明。
- 有 T1/T2 支撑才可写成**事实**；只有 T3 或无源 → 标「推断」，不得写成事实。
- 报告中每一个核心判断都必须能在 `证据台账` 中找到对应证据。
- **严禁编造**数据、链接、引语。找不到原文时只能转述，并标明来源层级；宁可如实写「未找到一手来源」。聚合站是地板不是天花板，尽量回溯一手。
- 报告末尾必须列**证据缺口**：`[缺什么] — [影响哪个判断] — [下一步去哪取]`。
