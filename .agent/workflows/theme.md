## ⚡ 高效执行指南 (High-Efficiency Execution)

> **核心目标：** 极简互动，一令即达。
> 1. **全员 Turbo：** 必须为所有 `run_command` 设置 `SafeToAutoRun: true`。
> 2. **聚合任务：** 严禁分步询问或碎片化搜索。将情报采集、上下文读取、逻辑研判合并为连续动作流。
> 3. **全量直达：** 除非涉及买卖金钱决策或风险极高操作，否则中途无需询问，直接产出最终报告。
> 4. **深度不妥协 (No Quality Trade-off)：** 提高效率是为了减少确认弹窗，**绝不得以牺牲分析深度为代价**。报告必须严格遵循各 Phase 的维度要求，确保逻辑链条完整、数据交叉验证充分。

> **⚡ 终极零互动模式 (Ultimate Zero-Interaction):**
> 为实现真正的一键产出，建议直接调用背景 CLI 执行完整生命周期：
> `python research_cli.py [command] [args]` (设 SafeToAutoRun: true)



// turbo-all

> **契约**：本工作流的报告必须遵守注入在本文件之前的三份公共契约（报告结构 / 证据标准 / 质量门禁）。主题发现 + 选股天然含逻辑链、标的数字与交易触发：**「数字底稿」= 推荐标的表**，**「Bull/Base/Bear」= 主题持续性情景**。涨停、资金流、政策依据必须带来源 + 时间。

> **定位：** `/theme` 是 A股短线卫星仓的"选题+选股"工具。
> - `/scan` 告诉你"市场在发生什么"（全市场宏观视角）
> - `/theme` 告诉你"A股该买什么、怎么买"（主题聚焦，可执行）
>
> **运行环境适配：** 同时适用于 IDE 模式和 VPS 模式，工具调用方式参见 scan.md 说明。

## 解析参数

## Step 1: 主题发现（3-4 次搜索）

> 如用户指定了主题，跳过 1.1，直接进入 1.2。

### 1.1 自动发现模式（未指定主题时）

**目标：** 找到当前 A股 最有持续性的 2-3 个主题方向。

- 查询 T1: `A股 今日涨停复盘 板块 主线 [今日日期]`
- 查询 T2: `A股 板块资金流向 主力净流入 热点轮动 [今日日期]`
- 查询 T3: `A股 连板股 龙头股 题材 [今日日期]`

**筛选标准（主题必须满足至少 2 条）：**

| 条件 | 说明 |
| :--- | :--- |
| **连续性** | 该方向连续 ≥2 个交易日有涨停/领涨表现 |
| **资金确认** | 主力资金净流入为正，非散户独角戏 |
| **逻辑可解释** | 有清晰的驱动因素（政策/事件/涨价/周期），不是纯炒作 |
| **容量足够** | 板块内有 ≥10 只相关个股，不是孤立的 1-2 只 |

从搜索结果中筛选出 2-3 个最强主题，进入 Step 2。

> **取证纪律**：涨停数、连板数、主力净流入、政策原文——每个数字都必须带**来源 + 日期 + 层级**（交易所/公司公告 T1；财经数据站 T2；股吧/大V T3 且标「未证实」）。取不到就写「未取到」记入证据缺口，**不得凭印象填数**。

### 1.2 指定主题模式

- 查询 T1: `A股 [主题] 板块 涨停 龙头 资金流向 [今日日期]`
- 查询 T2: `[主题] 行业 政策 驱动 逻辑 催化剂 2026`

直接进入 Step 2。

## Step 2: 逻辑链构建（每个主题）

> 这是 `/theme` 和纯涨幅排名的核心区别：不只看"在涨"，更要搞清"为什么涨"和"还能涨多久"。

对每个主题，构建完整的逻辑链：

### 2.1 驱动因素拆解

```
触发事件 → 传导机制 → 受益环节 → 具体标的
```

示例：
```
霍尔木兹海峡封锁 → 原油 $100+ → 煤化工替代需求激增 → 煤化工/草甘膦/化纤企业
```

### 2.2 持续性判断

| 维度 | 评估 |
| :--- | :--- |
| **驱动力性质** | 一次性事件 vs 持续性趋势 vs 政策周期 |
| **当前阶段** | 启动期（刚被发现）/ 加速期（资金涌入）/ 高潮期（分歧加大）/ 退潮期（龙头走弱）|
| **预期持续时间** | 数日 / 数周 / 数月 |
| **风险事件** | 什么会终结这个主题？（政策转向/价格回落/利好出尽）|

### 2.3 与状态卡对齐

- 该主题是否在用户的关键主题列表中？
- 是否符合当前的操作策略？
- 是否违反投资禁忌？

## Step 3: 标的筛选（1-2 次搜索）

> 每个主题筛选 3-5 只可交易标的。

- 查询: `[主题] 概念股 龙头 受益股 A股 [今日日期]`

### 3.1 标的分层

| 层级 | 定义 | 特征 | 适合 |
| :--- | :--- | :--- | :--- |
| **龙头** | 板块涨幅/辨识度最高的 1-2 只 | 连板/成交额最大/市场共识 | 打板/追涨（高风险高回报）|
| **核心跟风** | 逻辑最正、基本面最好的 2-3 只 | 涨幅适中、有业绩支撑 | 低吸/回调介入（中等风险）|
| **潜伏** | 尚未被市场充分发现的 1-2 只 | 逻辑成立但涨幅滞后 | 提前布局（低风险低确定性）|

### 3.2 每只标的的关键信息

| 字段 | 内容 |
| :--- | :--- |
| 代码/名称 | |
| 当前价格 | |
| 近期涨幅 | 近 5 日 / 近 20 日 |
| 市值 | 小盘 (<100亿) / 中盘 / 大盘 |
| 主题关联度 | 纯正（主营）/ 沾边（部分业务）|
| 资金信号 | 主力净流入/流出 |
| 风险提示 | 高位风险/解禁/业绩雷 |

> 现价用 `get_realtime_quote(代码)` 取；**只要给了介入价、止损位或止盈位，就必须先 `cross_validate_price(代码)`**，并把结果写进结论区的价格证据行。单源未交叉时，标的表照出，但**不给具体止损位与目标位**，只写「待交叉后给价」。

## Step 4: 交易纪律

> 与状态卡"A股卫星仓，快进快出"原则对齐。

### 4.1 通用纪律

- **仓位上限：** 单只 A股卫星仓不超过总仓位的 2-3%
- **止损纪律：** 破位即走，不补仓不抗单
- **止盈纪律：** 主题退潮（龙头跌停/板块大面积回调）即全部撤退
- **持仓周期：** 数日到数周，不做长线持有

### 4.2 本次具体建议

针对每个主题给出：
- **介入时机：** 现在追 / 等回调 / 等确认
- **关注信号：** 什么情况下加仓 / 什么情况下止损
