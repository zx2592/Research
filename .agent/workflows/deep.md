## Phase A: 逻辑骨架 — 商业模式与壁垒

**目标**: 搞清楚这家公司是什么、怎么赚钱、护城河在哪
> **⚠️ 模型要求**: 请务必使用 **gemini-3.1-pro-preview** 或同等级别最高智力模型执行此 Workflow。

### A1. 治理结构 (The Soul)
- **Missionary vs. Mercenary**: 创始人/CEO 是技术信仰者还是职业经理人？举例"至暗时刻"或"技术分叉口"的表现
- **核心团队稳定性**: 技术骨干背景及流失率
- **主要股东**: 机构持股比例，近期 Insider Trading

### A2. 商业壁垒 (The Engine)
- **模式简述**: 用通俗语言提炼核心盈利逻辑
- **护城河分析**: 网络效应、转换成本、技术代差、转移优势
- **反脆弱性**: 行业下行时，是吃掉份额还是率先受损？

### A3. 核心定性
- 提炼 **3 个关键增长驱动力**
- 一句话核心定性（如："困境反转的巨头" / "伪装成科技股的制造业"）

**搜索动作**: 公司年报/10-K 摘要、管理层背景、竞争格局

## Phase B: 数据验证 — 财务、盈利预测与估值

**目标**: 用数字支撑逻辑，给出清晰的财务画像和估值判断

### B0. 聚合数据采集
**⚡ 高效指令**: 仅限 1-2 次高密度搜索，覆盖财务、预期与评级。
1. `[Ticker] [Company] full financial summary 10-K revenue net income EPS consensus estimates 2026 2027 analyst price targets latest earnings call key takeaways`
2. (可选) `Short report [Ticker] bear case summary highlights`

**采集要点：**
- 核心财务三表数据、华尔街一致预期 (Revenue/EPS)
- 分析师评级分布与目标价区间
- 管理层最新指引 (Guidance)
- 市场主要负面逻辑/空头观点 (Bear Case)

**证据分级 (Evidence Tiers)**：交叉验证 ≥2 源之外，强制按来源层级取证——

| 层级 | 类型 | 示例 | 最低要求 |
| :--- | :--- | :--- | :--- |
| **Tier 1 一手** | 原始信号 | CEO 原话、员工评价(Glassdoor/脉脉)、客户评价(G2/App Store)、GitHub 活跃度、专利、招聘趋势、内部人交易(Form 4) | 全文至少引用 **3 处** |
| **Tier 2 事实** | 权威披露 | SEC 文件(10-K/10-Q/8-K/DEF 14A)、财务数据、法院文书 | **核心数据必须回溯到此层** |
| **Tier 3 观点** | 二手解读 | 卖方研报、新闻分析、目标价汇总 | 可引用，但**不得作为唯一依据** |

> 第三方聚合站是地板不是天花板——尽量回溯一手来源。找不到原话则转述并标注出处，**严禁编造引用**。
> **取数顺序**：A股先调 `get_financials(ticker)` 拿结构化年报底稿；其余市场先用 `browser_fetch` / `drill_source` 打开 10-K / 10-Q / IR 页面等结构化披露（收入、现金流、股本、净债务），再用 `search_web` 补一致预期与定性材料。两个来源都取到后，用 `cross_validate_metric(field, values, unit)` 算误差，按 ≤1% / 1-5% / >5% 三档如实写。**从新闻正文里读 OCF / FCF / ROIC 是数字出错的第一现场**——能回溯原始披露就不要停在文本转述。
> **联网取证一律走本项目工具**（`search_web` / `browser_fetch` / `drill_source` / `learn_source`）：走别处取到的原文这里留不下记录，证据台账事后无从回溯，等于没有证据。

### B1. 财务深度分析
- **现金流质量**: OCF vs Net Income（>1 为优质），FCF 长期趋势，CapEx 占比
- **资本效率**: ROIC / ROE（DuPont 拆解：利润率 × 周转率 × 杠杆）
- **资产负债健康**: Net Debt/EBITDA, Interest Coverage, 现金储备
- **北极星指标**: 该行业的第一性原理指标（SaaS→NDR, 电车→单车毛利, AI→推理成本）

### B2. 盈利预测
- **历史**: 近 3-5 年 Revenue / EPS 实际值
- **未来**: Consensus 预测 CY2026 / CY2027 Revenue Growth、EPS、Margin 变化
- **驱动假设**: 增长来自哪里？（量价拆分、新业务占比、市场渗透率）
- 使用 **Calendar Year (CY)**，财年需标注映射（如 "CY2026 ≈ FY27"）
- **必须交叉验证**（至少两个独立数据源）

### B3. 动态 PE 与估值分析
- **当前 PE (TTM)** 与 **Forward PE (CY2026/CY2027)**
- **历史 PE 区间**: 近 5 年 PE 的 High / Low / Median
- **当前百分位**: 当前 PE 在历史区间的位置（如 "处于 75th 分位，偏贵"）
- **PEG**: PE / EPS Growth，判断是否合理（<1 便宜, 1-2 合理, >2 偏贵）
- **反向 DCF (Reverse DCF)** — **必须用脚本算，不得心算**：

  ```
  execute_python_script("scripts/valuation_math.py",
    "--market-cap <市值> --shares <总股本> --fcf <基期自由现金流> --discount-rate 0.10 --terminal-growth 0.03 --years 10")
  ```

  - 报告里的**隐含增长率、安全边际价、终值占比、敏感性矩阵一律抄脚本输出**，
    不得自己估一个近似值。理由：心算结果无法复现，同一标的两次跑会得到不同数字。
  - 脚本 `status` 为 `fail` → 模型在数学上无效（如永续增长率 ≥ 折现率、基期 FCF 为负），
    **必须先修正输入再重跑**，不得带着 fail 的结果写估值结论。
  - 脚本 `status` 为 `warn` → 报告必须正面回应每一条 warn（尤其
    `implied_growth_plausible` 与 `terminal_value_share`），不得略过。
  - **脚本只做算术，判断仍归你**：「隐含增长率 32%」是算出来的，
    「32% 是否超过行业天花板、历史上同体量公司是否做到过」要你回答。
  - **判断**: 极度乐观(泡沫) / 合理定价 / 悲观错杀

### B4. 周期维度 (The Cycle)
- **行业阶段**: 导入期 / 成长期 / 成熟期 / 衰退期
- **宏观敏感度**: 利率、政策、地缘政治风险敞口
- **竞争终局**: 3-5 年后，为什么它还在牌桌上？

**搜索动作**: Financials, Earnings Estimates, Historical PE, Market Data

### B5. 价格取证（估值的分母）

1. `get_realtime_quote(ticker)` 取现价与抓取时间。
2. **本工作流要给目标价与安全边际价 → 必须 `cross_validate_price(ticker)`**，把 `passed` / `spread_pct` / `sources` 如实写进结论区的价格证据行。
3. `passed: false` 或 `fewer than two price sources` → 写「单源未交叉」，**本次不给目标价、安全边际价与盈亏比**，估值三角只给倍数与隐含增长率。
4. `identical_values: true` 时先确认两源不是同一份行情的两个门面，确认不了按单源处理。
5. 市值 / 股本口径用 `verify_market_cap(price, shares, reported_cap)` 验算一遍，偏差 >5% 先回原始披露核对增发、回购、库存股与 ADR 存托比率。

## Phase C: 挑战 — 压力测试

**目标**: 从空头视角摧毁自己的逻辑

### C1. Bear Case
- 扮演 Short Seller，找 3-5 个弱点或风险
- 搜索 "Short report [Ticker]" / "Bear case [Ticker]"
- 综合形成「反论文 (Anti-Thesis)」

### C2. 多空博弈
- **Bull Case**: 市场主流买入理由
- **Bear Case**: 市场主要担忧与风险
- **预期差**: 当前估值计入了什么？市场遗漏了什么？

### C3. 致命风险清单 (Pre-Mortem)与红旗扫描
- 列出 **3 个可能导致投资逻辑失效的致命风险**
- **红旗扫描 (Red Flags)**:
  - **US (美股)**: SBC过度稀释真实FCF, Adjusted指标滥用, 债务契约压力, 并购堆砌商誉
  - **HK (港股)**: 频繁低价配售/供股, 关联交易输送, 利润好但现金差 (营运资本异常)
  - **JP (日股)**: 现金躺平, 交叉持股不作为, 治理改革仅停留在口号

### C4. 交易决策与规则 (Actionable Plan)
- **建仓**: 分批规则（价格折价阈值或事件触发）
- **跟踪**: 哪 3 个核心 KPI 恶化时，必须承认看错并离场
- **退出**: 假设证伪 / 治理恶化 / 隐含回报过低 / 护城河不可逆破坏
