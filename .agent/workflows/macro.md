> **契约**：本工作流的报告必须遵守注入在本文件之前的三份公共契约（报告结构 / 证据标准 / 质量门禁）。**流动性指标必须带读数 + 读数时间**，无时间戳的读数一律视为过期。

## ⚡ 高效执行指南 (High-Efficiency Execution)

> **核心目标：** 极简互动，一令即达。
> 1. **全员 Turbo：** 必须为所有 `run_command` 设置 `SafeToAutoRun: true`。
> 2. **聚合任务：** 严禁分步询问或碎片化搜索。将情报采集、上下文读取、逻辑研判合并为连续动作流。
> 3. **全量直达：** 除非涉及买卖金钱决策或风险极高操作，否则中途无需询问，直接产出最终报告。
> 4. **深度不妥协 (No Quality Trade-off)：** 提高效率是为了减少确认弹窗，**绝不得以牺牲分析深度为代价**。

> **⚡ 终极零互动模式 (Ultimate Zero-Interaction):**
> 为实现真正的一键产出，建议直接调用背景 CLI 执行完整生命周期：
> `python research_cli.py [command] [args]` (设 SafeToAutoRun: true)

## 解析参数

- `/macro [Event]`（如 `/macro 美联储加息50bp`）
- `/macro [Event] [Ticker]`（如 `/macro 关税战升级 NVDA`）

> 无 Ticker 时对整体持仓做压力测试（先 `get_portfolio_snapshot`），有 Ticker 时聚焦个股。

## Step 1: 宏观事件定性

用 `search_web` 搜索事件最新进展（每条带**来源 + 时间**），确认：
- 事件性质与严重程度
- 市场当前反应（恐慌 / 淡定 / 尚未消化）
- 区分**已发生的事实 (T1/T2)** 与**市场解读 (T3)**

---

## Step 2: 三维压力测试

### 2.1 贴现率敏感度 (Valuation Risk)
- 事件是否导致 WACC 上升？
- 高增长 / 不盈利 / 长久期标的受冲击最大
- 目标标的的久期（Duration）有多长？
- **量化流动性温度**（告别纯定性，1 次高密度搜索确认"水管"状态）：

  | 指标 | 序列代码 | 🔴 预警线 | 对估值的传导 |
  | :--- | :--- | :--- | :--- |
  | MOVE 指数 | `MOVE` | > 130 | 美债波动放大折现率不确定性，机构被迫降险 |
  | SOFR vs 准备金利率 (IORB) | `SOFR_IORB_SPREAD` | > +10bp | 短端钱荒，融资成本骤升 |
  | Fed 净流动性 (总资产−TGA−RRP) | `NET_LIQUIDITY` | 单周降 >5% | 系统性抽水，高久期资产首当其冲 |
  | USDJPY 周跌 / 美日 2Y 利差收窄 | `USDJPY` / `DGS2` | >3% / 月>50bp | 套息平仓 → 全球去杠杆 |
  | 高收益债 OAS | `BAMLH0A0HYM2` | 月走阔 >100bp | 信用收缩，危机旗标的第一票 |

  > **每个读数必须写清「数值 + 读数时间 + 来源」**——"我什么时候知道的"和"数是多少"同样重要，全部进证据台账与数字底稿。
  > **取不到就如实写「未采集」**，记入证据缺口；**不得用市场评论或印象冒充读数**，也不得沿用训练记忆里的历史值。
  > 命中越多，贴现率冲击越实锤；**0 命中则本次更可能是情绪扰动而非流动性危机**（这条同时是本报告的反方）。

### 2.2 业务传导机制 (Operational Risk)
- **成本端**: 原材料 / 能源价格上涨 → 冲击毛利？
- **需求端**: 经济放缓 → 客户削减预算？
- **供应链**: 地缘冲突 → 供应中断？

### 2.3 避险属性 (Safe Haven Check)
- 该标的在此背景下是资金的"避风港"还是"提款机"？
