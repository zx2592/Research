# Workflow Rules (工作流规则)

> 本文件记录了你在执行任务时必须遵守的永久性操作规则。

## 1. 指令行为 (Command Behavior)

*   **`/research` & `/verify`**:
    *   **Rule**: 凡是执行这两个指令，**必须**生成一份独立的 Markdown 报告。
    *   **Storage**: 报告必须保存在当天的 `Reports` 目录下，路径结构为 `.../Research/Reports/[YYYYMMDD]/[Topic]_[YYYYMMDD].md`。
    *   **Content**: 报告应包含核心观点、数据支撑、以及相应的引用。
